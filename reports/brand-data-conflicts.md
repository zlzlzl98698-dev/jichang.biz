# 品牌数据冲突与核验记录报告 (Brand Data Conflicts & Verification Audit)

## 1. 核验背景与审计原则
跨境网络服务市场的公开信息普遍存在商家营销夸大、不同时期活动页面残留、第三方测速博主口径不一等严重数据污染问题。
「机场指南」项目严守**“诚实标记、来源留痕、冲突共存、杜绝粉饰”**原则，严禁为了字段工整而编造虚假测试数据，亦严禁凭空捏造不存在的第 32 家品牌。

## 2. 核心冲突清单与代码级处理结果

### 2.1 光速云（guangsu）：流量摘要与详情表冲突
- **历史冲突记录**：在附录原始资料中，光速云入门套餐在摘要段落标注为“59GB/月”，而在详细资费表格中列示为“69GB/月”。此外，其宣传“8.25元/月”实为 99 元年付套餐折算后的等效均价，并非按月结算的单月门槛（其实际单月起步为 25 元/月）。
- **核验处理策略**：
  1. 在 `src/data/brands.ts` 中保留该冲突记录，明确在套餐备注标注：“历史资料摘要称59GB与详情69GB存在记录冲突，标注待核实；折合约8.25元/月”；
  2. 在 `/brands/guangsu/` 与 `/reviews/guangsu/` 的 Answer-First 结论中向用户明确说明：8.25 元/月需一次性年付 99 元，初次试用强烈建议先选 25 元月付套餐进行本地晚高峰匹配。

### 2.2 Firefly 与 Firefly 萤火虫：别名去重与实体合并
- **历史冲突记录**：资料库中分别存在以英文名“Firefly”和中文名“Firefly 萤火虫”记录的两个条目，且包含两套不同的历史推广入口。
- **核验处理策略**：
  1. 经 WHOIS、官方 TG 发布历史与机房入口 IP 交叉比对，确认为同一家服务商在不同推广渠道的别名；
  2. 合并为唯一实体 ID `firefly`，中文别名设置为 `Firefly 萤火虫`；
  3. 剔除失效历史邀请码，仅保留自动化存活探测通过的有效入口；
  4. 确保全站品牌实体总数严格锁定在 **31 家**，杜绝同名重复计入。

### 2.3 微风网络（weifeng）：摘要起步价与套餐表差异
- **历史冲突记录**：部分推广渠道宣传“7.9元/月”，但官网实际月付基础套餐标价为 9.9 元/月，季付以上方可折合 8.x 元。
- **核验处理策略**：
  1. 在资费表中以官方结账账单标价 9.9 元/月作为基础展示，不采用未经证实的超低价作为宣传口径；
  2. 明确标注折扣码适用范围（通常仅限季付或年付周期）。

### 2.4 唯兔云（weitu）：活动促销价与常态标价冲突
- **历史冲突记录**：宣传页列示节假日限时特惠 14.9 元/月，但非促销时段常规套餐门槛为 19.9 元/月。
- **核验处理策略**：
  1. 标记数据状态为 `vendor`；
  2. 在评测中注明：“14.9 元为特定活动促销折算价，常规月份以结账页实际显示金额为准”。

### 2.5 隐形人加速器（yinxingren）：设备限制与优惠码生效条件
- **历史冲突记录**：早期资料宣传“不限设备”，但后续服务条款更新为“同时在线公网 IP 不得超过 3 个”，否则系统触发速率限制。
- **核验处理策略**：
  1. 修正客户端并发说明，由“无限制”纠正为“建议 3 台以内常用设备同时连接”；
  2. 针对其优惠码添加“需单笔满 50 元方可抵扣”的前置说明。

### 2.6 云界线（yunjiexian）与 环球梯（quanqiu）：邀请链接格式异常
- **历史冲突记录**：部分历史原始文本包含带有异常符号（多余反斜杠或转义符）的邀请代码，直接拼接入浏览器会导致 404 重定向。
- **核验处理策略**：
  1. 对链接进行正则净化，移除多余转义字符；
  2. 经由 `scripts/link-check.cjs` 统一实施可用性扫描与 `target="_blank" rel="nofollow sponsored noopener"` 语法强制校验。

### 2.7 附录三家新增实体（灵动云、浪网、EdgeNova）收录规范化
- **历史记录**：作为附录新扩充的服务商，部分基础字段（如最早确切开业月份、自研客户端是否有单独软著）存在留白。
- **核验处理策略**：
  1. 数据状态统一标注为 `vendor` 或 `unknown`；
  2. 明确给出已测得的 IEPL/IPLC 专线延迟范围，缺失字段明确标红“待核实补充”，坚决杜绝填充虚构试用记录。

## 3. 冲突治理长效机制
全站所有品牌数据统一收敛于 `src/data/brands.ts` 单一真相来源（Single Source of Truth）。
每次构建均由 `scripts/validate.cjs` 自动进行 31 家去重实体断言与字段完整性校验，从根本上防止数据回退或冲突失控。
